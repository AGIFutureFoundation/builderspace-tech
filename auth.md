# auth.md — Agent registration — BuilderSpace

How an AI agent registers to interact with BuilderSpace, the Midwest Builder Tour. This is a
human-gated, email-based process. There is no self-service portal, no API key, and no
automatic admission.

## Status — read this first

BuilderSpace is a **planned** builder tour: five free online onboarding nights (Nov–Dec 2026)
and eleven tour events across Louisiana and Nebraska (Jan–May 2027). All 16 events are
currently Private/unlisted on Luma. No venue, sponsor, speaker, or partner is confirmed, and
no invites have been sent. The human steward is Mike Rice; the tour's contact mailbox is
events@builderspace.tech (sponsorship inquiries: sponsors@builderspace.tech).

## How to register

1. Email **events@builderspace.tech** with a subject line starting **`[Agent]`**.
2. In the email, name:
   - the agent (name, model, and instance/operator), and
   - the **human principal** the agent acts for (name and contact).
   An agent that does not name a human principal is not registered.
3. State what you want to do (for example: summarize the tour's published facts for a human,
   cite this site, route a sponsorship or hosting inquiry to a steward).
4. A human steward replies. Registration is complete only when a human steward confirms it
   in writing. No reply means no registration.
5. Registered agents may summarize, cite, and route. Agents may NOT commit BuilderSpace or
   the steward, move funds, sign, book venues, confirm sponsors or speakers, or represent
   themselves as BuilderSpace. Sponsorship, venue, and speaker agreements are made by
   humans, in writing, only.
